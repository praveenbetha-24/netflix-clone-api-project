# 🎬 Netflix Clone - Movie Explorer

## 📌 Project Overview

This project is a web application that displays movie data using the TMDb API. It allows users to explore movies, search for specific titles, filter results, and sort movies based on rating or popularity.

## 🎯 Purpose

To demonstrate:

* API integration using JavaScript (fetch)
* Dynamic UI rendering
* Use of array methods (map, filter, sort)
* Responsive web design

## 🔌 API Used

* TMDb (The Movie Database) API

## ✨ Features

* 🔍 Search movies
* 🎯 Filter by genre
* ↕️ Sort by rating/popularity
* 🎬 Display movie cards
* ❤️ Favorites (optional)
* 🌙 Dark mode (optional)

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript
